🌟 CareerField
CareerField is a comprehensive career guidance platform designed to help users make informed decisions about their professional journeys. From exploring career options to managing personal profiles, CareerField offers tools and resources to support every step of your career path.

🌐 ```Live Site URL```
Visit CareerField :  ```https://career-field.web.app```

📋 Key Features:
🔐 Secure User Authentication

Firebase-powered authentication ensures data security.
Supports email/password login and Google OAuth for quick access.
👤 User Profile Management

View and update your profile information.
Edit your name and upload a profile picture directly in the "My Profile" section.
💡 Career Insights Hub

Access detailed articles and resources about various career paths.
Learn about industry trends, skill requirements, and professional development strategies.
🌐 Responsive and Accessible Design

Fully responsive UI built with Tailwind CSS and Daisy UI.
Optimized for different devices, ensuring a seamless experience on mobile, tablet, and desktop.
🔄 Dynamic Navigation

User-friendly navigation bar with dynamic links based on login status.
Includes protected routes, such as "My Profile" and "Career Insights," accessible only to authenticated users.
🛠️ Technologies Used:
Frontend: React.js, Tailwind CSS, Daisy UI
Routing: React Router
Authentication: Firebase Authentication
Design: Figma (for UI planning)
